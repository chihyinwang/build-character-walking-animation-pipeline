# Character artifact layout

Use a character root such as `~/Desktop/Sprites/npc-01`.

```text
<character-root>/
  spec/
    character-spec.yaml
  approvals/
  anchors/
    raw/
    processed/
    canonical/
    review/
    direction-manifest.yaml
  actions/
    walking/
      manifest.json
  video-requests/
    walking-<direction>/
  videos/
    walking-<direction>/
  all-frames/
    walking-<direction>/
  key-frames/
    walking-<direction>/
      timeline-overview/
      phase-map.json
      proposed-selection.json
      proposal-phase-validation.json
      proposal-motion-validation.json
      selection.json
      phase-validation.json
      motion-validation.json
      pixel-snapped/
      frame-source.json
  runtime/
    walking-<direction>/
      frames/
      spritesheet.png
      preview.gif
      preview-repeated-4x.gif
      preview-light.gif
      preview-dark.gif
      manifest.json
      alignment.json
      qa.json
```

All stored paths are relative to `<character-root>`. User-returned walking videos may originate elsewhere, but ingestion copies them into this layout without retaining the original absolute location. Still-image anchors are generated by Codex and are never a user handoff.
